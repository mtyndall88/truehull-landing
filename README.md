# TrueHull Landing Page

This repository hosts the guarded public landing page for [gettruehull.com](https://gettruehull.com).

TrueHull is an early-stage boat buyer due-diligence platform. This landing page is intended for partnership and business inquiries while the product is in development.

## Deployment

The site is deployed with GitHub Pages using GitHub Actions. The workflow publishes this static repository only.
